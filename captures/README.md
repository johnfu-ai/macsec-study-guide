# captures/

Committed reference PCAPs for Wireshark / tshark. Regenerated by `make generate`.

| File | What to study |
|---|---|
| `session-full.pcap` | MKA then MACsec in one file — open this first |
| `mka-handshake.pcap` | EAPOL-MKA (`0x888E`, type 5): Key Server election, Potential/Live Peer List, Distributed SAK, SAK Use (PSK CAK) |
| `mka-after-eap.pcap` | EAP-Success then the same MKPDU sequence; CAK/CKN derived from MSK; Authenticator is Key Server |
| `mka-rekey.pcap` | SAK rekey: AN=0 → AN=1, KN rotation, old SAK retire (needs `LabKeys.sak2`) |
| `mka-co30.pcap` | Confidentiality Offset 30: inner IP header stays cleartext (AN 2, `sak3`) |
| `mka-xpn.pcap` | XPN suite: suite ID in Distributed SAK, SSCI/salt, PN64 past the 2^32 wrap (MKA version 3, `sak4`) |
| `mka-multi-peer.pcap` | 3-node CA: one CAK, one KS, one SAK, three SCs |
| `mka-delay-protect.pcap` | Delay Protect: SAK Use advertises lowest acceptable PN; held frames expire |
| `macsec-lab-encrypted.pcap` | Lab GCM-AES-128, E=1 C=1. Inner IPv4 is ciphertext. Decrypt with `keys.json` → `sak` |
| `macsec-lab-integrity-only.pcap` | Same ICMP, E=0 C=0. Inner `0x0800` IPv4 is visible; ICV still covers the frame |
| `macsec-replay.pcap` | Receive-side replay window: out-of-order accepted, replay/duplicate dropped (model `ReplayWindow`) |
| `macsec-ieee-gcm-aes-128-integrity.pcap` | Official IEEE GCM-AES-128 integrity vector (Randall 2011) |
| `macsec-ieee-gcm-aes-128-encrypt.pcap` | Official IEEE GCM-AES-128 confidentiality vector |
| `macsec-ieee-gcm-aes-256-integrity.pcap` | Official IEEE GCM-AES-256 integrity vector |
| `macsec-ieee-gcm-aes-256-encrypt.pcap` | Official IEEE GCM-AES-256 confidentiality vector |
| `keys.json` | Demo PSK CAK plus `eap` object (MSK / derived CAK / CKN / SAK / KEK / ICK) |
| `frame-index.json` | One-line comment per frame |
| `decoded/` | 每条消息的偏移字段表 + tshark `-V`（`make generate`，书籍附录 D） |

密钥层次（CAK 从不加密用户帧；SAK 不是 `KDF(CAK)`）：[第二章 密钥体系](../02_key_hierarchy/README.md)。
完整会话的中文逐帧说明还写在[第五章 报文字节级解析](../05_wire_format/README.md)（控制面六帧 / 数据面七帧）。

## Wireshark

```
Filter:  mka || macsec
MKA:     eapol.type == 5
MACsec:  eth.type == 0x88e5
```

To let Wireshark verify MKA ICV and unwrap the SAK: **Preferences → Protocols → MKA** → CKN table, add CKN + CAK from `keys.json`.

WSL2 + Windows Wireshark:

```
\\wsl$\<distro>\home\<you>\macsec-study-guide\captures\session-full.pcap
```
